# 💜 DESEJOS – Tayna & Guilherme

Jogo HTML5 / PWA de desejos para casal.

## Como jogar

1. Abra o site no celular
2. Login:
   - **Tayna** → senha `12124800`
   - **Guilherme** → senha `105046`
3. Escreva desejos · Revele · Cumpra em 6 dias · Confirme

## Deploy

Projeto configurado para **Vercel** (ou GitHub Pages).

- `index.html` — app principal
- `manifest.json` + `sw.js` — PWA
- Ícones em PNG

### Vercel

1. Importe o repositório em [vercel.com](https://vercel.com)
2. Framework Preset: **Other**
3. Deploy

Depois de publicado, no celular: **Adicionar à tela inicial** para instalar o PWA.

## Stack

HTML5 · CSS · JavaScript · MockAPI · PWA · Web Audio · Vibration API
